# src/net/uci — UCI / U64E backend (future)

Placeholder for the Ultimate Command Interface networking backend,
targeting the Commodore Ultimate 64 / U64E. Will implement the same
`net_*` ABI as the ip65 backend, letting c64-https run natively on
U64E without RR-Net hardware.

Not implemented yet. Select via `BACKEND=uci` in the Makefile (also
not functional yet).
